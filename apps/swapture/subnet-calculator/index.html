What Is a Subnet Calculator?

A subnet calculator helps network engineers, system administrators, and students quickly determine the properties of an IP subnet. Enter any IPv4 address and either a CIDR prefix length (e.g., /24) or a dotted-decimal subnet mask (e.g., 255.255.255.0) to instantly see the network address, broadcast address, usable host range, and more.

Key Subnet Concepts

  • Network Address — the first address in the subnet, used to identify the network itself.
  • Broadcast Address — the last address in the subnet; packets sent here reach all hosts.
  • First / Last Usable Host — the actual range of assignable IP addresses.
  • CIDR Notation — a compact representation like 192.168.1.0/24.
  • IP Class — the traditional Class A/B/C/D/E classification based on the first octet.

Frequently Asked Questions

What is a subnet mask?
A subnet mask is a 32-bit number that divides an IP address into a network portion and a host portion. It uses consecutive 1 bits to identify the network part and 0 bits for the host part. For example, 255.255.255.0 (or /24 in CIDR notation) means the first 24 bits are the network address and the remaining 8 bits identify hosts within that network.
What is CIDR notation?
CIDR (Classless Inter-Domain Routing) notation represents an IP address and its subnet mask as a single expression by appending a slash and a number (0–32) to the IP — e.g., 192.168.1.0/24. The number indicates how many leading bits are the network prefix. This is more flexible than the older classful system and enables efficient IP address allocation.
How do you calculate the number of usable hosts in a subnet?
The total number of addresses in a subnet is 2(32 − prefix length). Subtract 2 for usable hosts: one address is reserved as the network address and one as the broadcast address. For example, a /24 subnet has 28 = 256 total addresses and 254 usable host addresses. Special cases: a /31 subnet has 2 addresses (used for point-to-point links per RFC 3021) and a /32 identifies a single host.
