¿Cómo funciona?

El tipo de cambio se obtiene en tiempo real desde Open Exchange Rates. Si no hay conexión disponible, se muestra una tasa referencial reciente.

Solo de referencia. Para transacciones financieras use el tipo de cambio oficial del Banco Central de Costa Rica (BCCR).

Preguntas frecuentes

¿Con qué frecuencia se actualiza la tasa?
La tasa se actualiza diariamente en días hábiles bancarios, con datos provenientes del mercado de divisas interbancario.
¿Puedo usar esta tasa para transacciones reales?
Solo de referencia. Para cambios de divisa use la tasa oficial del BCCR o la que establezca su banco.
¿Por qué difieran las tasas entre bancos?
Cada entidad aplica un margen (spread) propio sobre la tasa de mercado. La diferencia entre compra y venta depende de cada institución.
